# 💥 BLAST RUN 💥

### Retro Neon Tactics

**BLAST RUN** — Bomberman-like игра с элементами рогалика: прокладывайте путь взрывами, ищите скрытые порталы, сражайтесь с боссами и улучшайте своего героя.

## ✨ Особенности

- 🎮 Пошаговое движение в духе классических тактических игр.
- 💣 Бомбы, кислотные заряды и цепные реакции.
- 👻 Разные враги: слаймы, бегуны, танки и призраки.
- 🦸 Три героя — Нео, Ниндзя и Инженер — с уникальными способностями.
- 👑 Пять видов боссов, включая Глаз Омега и Ледяного Колосса.
- 🌀 Скрытые порталы, разрушаемые блоки и процедурно создаваемые уровни.
- 🎵 Синтезированная музыка и звуковые эффекты на Web Audio API.
- 💰 Игровая экономика: золото, янтарь, улучшения и артефакты.

## 🕹️ Управление

| Действие | Клавиши |
|---|---|
| Движение | `W` `A` `S` `D` или клавиши-стрелки |
| Поставить или подобрать бомбу | `Пробел` |
| Перезапустить раунд | `R` |

## 🚀 Запуск

Скачайте или клонируйте проект и откройте `index.html` в современном браузере. Для корректной загрузки изображений папка `assets` должна находиться рядом с файлом `index.html`.
